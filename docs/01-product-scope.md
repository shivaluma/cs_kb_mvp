# 01. Product Scope

This is the short scope summary. The fuller PRD breakdown lives in `01-product-requirements.md`.

## P0

- Authentication and RBAC
- SOP repository with version workflow
- Keyword search with filters
- Taxonomy and controlled tags
- Structured SOP detail page
- Homepage with search, recent, popular
- Analytics logging
- Excel migration
- Audit logging

## P1

- Semantic search
- AI suggestion with citations
- Helpful / not helpful feedback
- Rollback
- Synonym and alias management

## Non-goals

- AI makes policy decisions
- External chatbot
- Full CRM automation
- Complex workflow engine
- Real-time sync from all legacy sources
